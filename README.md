# idc. — A quiz for the unbothered 💅

An interactive, multi-step web application built with Next.js and Framer Motion for responding to essay-length text messages. Created as a personal development project to practice web animations, physics interactions, and UI layout.

## Credits & Inspiration

This project is a recreation fully inspired by [this post on r/shitposting](https://www.reddit.com/r/shitposting/s/oSDHzwRTCc). All original concept, joke, and flow credits belong to the original author/creator featured in that post!

## Features
- Dynamic slide progression layout
- Evasive target buttons
- Physics-driven vertical scale slider with simulated gravity bounce
- Responsive mobile & desktop interface using Tailwind CSS
